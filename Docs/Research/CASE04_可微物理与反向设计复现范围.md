# Case 04：可微物理与反向设计复现范围

## 作品主张

本 Case 定位为“可微动力学与反向设计的 UE 工程复现”，不声称完整复现某一篇论文。SIGGRAPH 近年相关研究覆盖可微旋转动力学、PDE/Flow Map 伴随法、软气动执行器设计、可微服装和结构曲面优化；当前首切片先解决一个规模小但可严格验证的共同内核：从目标末端状态反演阻尼弹簧执行器的驱动力与阻尼。

## 首切片数值合同

- 状态为一自由度质量点的位置和速度，质量归一化为 1；驱动力、线性刚度和阻尼均为显式参数。
- 前向解使用固定步 semi-implicit Euler。每个参数的切线位置/速度与原状态在完全相同的离散顺序中推进，避免用连续公式替代实际离散程序的导数。
- 目标损失同时包含末端位置和速度，避免只匹配落点却保留错误动量。
- 三个解析切线梯度都必须与中心有限差分在独立自动化中相符；优化器只消费解析切线梯度，有限差分只是真值门。
- 首个反演用已知参数生成确定性目标，再从错误的驱动力和阻尼出发恢复参数，保存每轮损失曲线。后续加入不可辨识短时域或冲突目标作为失败案例。

## UE / Chaos 分层

| 层 | UE / Chaos 职责 | 个人实现 |
| --- | --- | --- |
| 世界与资产 | Actor、Static Mesh、约束组件、输入和场景生命周期 | 参数化实验装配与目标标记 |
| Chaos 对照 | 刚体质量、弹簧/阻尼约束和碰撞重放 | 把拟合参数送入 Chaos，并量化模型偏差 |
| 可微前向模型 | 不使用 Chaos 内部不可公开导数冒充梯度 | 固定步状态更新、切线灵敏度与损失 |
| 反向设计 | 不把 UI 滑条称为优化 | 受界投影、线搜索、收敛曲线和失败诊断 |
| 表现 | UE 渲染、Debug Draw、中文 HUD | 优化前/后轨迹、目标误差和梯度检查可视化 |

Chaos 在本 Case 中是最终重放与引擎集成基线，不是可微后端。研究模型和 Chaos 使用相同名义质量、刚度、阻尼、初态与固定步，但必须报告两者离散/约束实现造成的轨迹差异，不能要求数值完全相同。

## UE / Chaos 运行切片

独立地图 `/PhysicsInverseDesign/Maps/L_InverseSpringChaosReplay` 已把首切片接入真实运行态。目标、错误初值、优化研究模型和 Chaos Constraint 四路轨迹同屏；数学状态用 100 cm/model-unit 只做显示尺度换算。Chaos 约束的 X 位置/速度 Drive 消费恢复的刚度和阻尼，目标位置为 `scale×drive/stiffness`，因此与研究方程拥有相同平衡点和名义参数。

120 个 60 Hz 固定步中，Chaos 刚体移动 228.956 cm；研究模型末端目标误差 0.001135 cm，Chaos 对研究轨迹 RMS 9.6281 cm、末端目标误差 0.14554 cm。该差异来自 Chaos Constraint 与 semi-implicit 参考模型的离散、约束求解及采样时序差异，作为引擎集成证据保留，而不是调参到逐帧重合。

## 完成边界与冻结状态

- 已完成 1-DOF 阻尼弹簧、2D 阻力弹道、6-DOF 分段弹簧链三个标准基准；每个基准都有同离散切线/有限差分真值、参数恢复和不重复的不可辨识边界。
- 已完成独立 UE 地图、Chaos Constraint 同参数重放、CSV/JSON、真实 GUI 截图、完整玩家交互和运行态病态目标切换；最终场景明确展示研究模型与 Chaos 的离散偏差。
- 尚未实现反向模式/伴随法、旋转导数、接触不连续、PDE 形状梯度或 GPU 优化；后续只有在多参数/长时域使前向切线成本成为真实瓶颈时才引入伴随法。
- 弹簧链 4/8/16 质量点各 96 次评估已报告 mean/P95；当前只优化两个空间参数，数据不支持引入伴随法的工程成本。
- 本 Case 不声称完整复现论文，也不声称 Chaos 内部可微。Case04 以“前向切线工程复现 + Chaos 同参数重放”的范围进入冻结状态；伴随法、接触/旋转导数和更复杂美术包装移入可选增强，不阻塞 Case05。
